# 01 · 产品方案

## 1. 产品定位

**一建通** —— 一级建造师考生的「刷题 + 听课 + 模考 + 进度管理」一体化备考工具。

一句话价值主张：**让在职工程人在每天 30 分钟的碎片时间里，知道自己该学什么、错了什么、离及格还差多少。**

### 1.1 与市面产品的差异点

| 维度 | 市面主流（粉笔/嗨学/233 等） | 一建通 |
|---|---|---|
| 核心交互 | 课程驱动，买课后看视频 | **任务驱动**，每天打开首页就是「今日 20 题 + 1 节课」 |
| 目标感 | 弱，靠用户自律 | **强**，倒计时 + 及格线预测 + 掌握度进度环 |
| 错题 | 简单错题本 | **记忆曲线重练**（SM-2），到期自动推 |
| 主观题 | 看一眼参考答案 | **自评 + 教研人工评**双通道，评分标准可逐条打分 |
| 移动端 | APP 装包 200MB+ | **H5/PWA 秒开**，可加桌面图标，弱网可离线刷题 |
| 教师/教研 | 无工具 | **教研工作台**：录题、审核、组卷、看题目区分度 |

### 1.2 目标用户画像

**画像 A：在职施工员 / 技术负责人（核心，占 65%）**
- 28–40 岁，男性为主，工地/项目部环境，通勤与午休是主要学习窗口
- 手机为绝对主力设备，网络时好时坏
- 痛点：时间碎、自律差、做题没方向、案例题不知怎么拿分
- 付费意愿：中高（考试直接关联收入与职级）

**画像 B：二战/三战考生（占 20%）**
- 已了解考试，知道自己薄弱
- 痛点：上次差几分，需要精准补漏
- 对「薄弱点分析」「历年考点分布」需求最强

**画像 C：增项考生（占 10%）**
- 已有一建证书，只考实务一科
- 需求极窄：只看实务，且要专业对口

**画像 D：零基础转行（占 5%）**
- 需要从零规划，学习计划向导是刚需

### 1.3 考试基本信息（产品内置常量，需按年更新）

| 项目 | 内容 |
|---|---|
| 科目 | ① 建设工程经济（客观题，100 分，2h）② 建设工程法规及相关知识（客观题，130 分，3h）③ 建设工程项目管理（客观题，130 分，3h）④ 专业工程管理与实务（主客观混合，160 分，4h） |
| 实务专业 | 建筑、公路、铁路、民航机场、港口与航道、水利水电、市政公用、通信与广电、矿业、机电（共 10 个） |
| 成绩规则 | 考全科须在 **连续 2 个考试年度内**通过全部 4 科；免二科须 1 年内通过；增项只考实务 |
| 报考门槛 | 工程类专科 +4 年 / 工学本科 +3 年 / 硕士 +2 年 / 博士 +1 年 |
| 近年考期 | 报名 6 月中下旬，考试 9 月中旬（近两年均为 9 月第二个周末） |
| 成绩公布 | 次年 12 月中旬前后 |

> **当前时点说明（2026-09-15）**：2026 年度考试已于 9 月 12–13 日结束。因此平台首页默认切到 **「考后复盘模式」**：倒计时指向 2027 年考季（预计 9 月中旬，具体等官方通知），同时开放「对答案 / 估分 / 成绩预约提醒」。这个切换由 `exam_calendar` 表驱动的状态机控制，不写死在代码里。

## 2. 用户角色与权限矩阵

| 角色 | 代码 | 说明 | 核心权限 |
|---|---|---|---|
| 游客 | `guest` | 未登录 | 浏览科目/章节树、试看免费课、试做每日一练前 3 题 |
| 学员 | `student` | 已注册 | 学习、刷题、模考、笔记、错题本、个人报告 |
| 付费学员 | `student_vip` | 有有效权益 | 全部课程 + 全题库 + 人工批改 + 无限模考 |
| 教师 | `teacher` | 授课老师 | 自己的课程管理、答疑、直播、学员学习情况 |
| 教研 | `researcher` | 题库负责人 | 题目增删改、审核、组卷、发布/回滚、导入导出 |
| 运营 | `operator` | 内容运营 | 公告、Banner、推送、优惠券、订单查看 |
| 管理员 | `admin` | 系统管理员 | 用户/角色/权限、订单与退款、系统配置、审计日志 |
| 超管 | `super_admin` | 系统拥有者 | 全部 + 权限分配 + 危险操作（回滚/清库） |

### 权限模型

采用 **RBAC + 数据范围（Data Scope）** 双层：

```
user --(user_roles, 带 scope_type/scope_id)--> role --(role_permissions)--> permission
```

- `permission.code` 形如 `question:create`、`question:publish`、`order:refund`、`user:export`
- `scope_type` 支持 `global` / `subject`（限定科目）/ `professional`（限定专业）/ `course`（限定课程）
- 例：某教研只负责「市政公用工程」，则 `user_roles.scope_type='professional', scope_id=<市政>`，他只能看到并操作市政实务的题。

## 4. MVP 边界定义

### 4.1 MVP 必须交付（Batch 2 + Batch 3）

```
登录注册 → 选科目/专业 → 章节树 → 章节练习/每日一练/随机练习
       → 答题与解析 → 错题本 → 全真模考 → 成绩报告 → 学习统计
后台：题库导入 → 审核 → 发布 → 组卷
```

**明确不做（放 P1/P2）**：微信登录、支付、直播、小程序、APP、AI 答疑、离线视频下载、人工批改。

### 4.2 MVP 验收标准

| 指标 | 目标 |
|---|---|
| 题库规模 | ≥ 6000 题可检索可作答 |
| 首屏（4G 弱网） | < 2.5s 可交互 |
| 答题接口 P95 | < 150ms |
| 模考中断恢复 | 100% 可恢复且答案不丢 |
| 移动端适配 | 375px 宽度无横向滚动、可单手操作 |
| 离线可用 | 断网后可继续做已缓存题目，联网后自动同步 |

## 5. 商业化设计

| 模式 | 说明 | 定价锚点（参考） |
|---|---|---|
| 单科课程 | 按科购买，含讲义+视频+题库 | ¥299–599 / 科 |
| 全科套餐 | 4 科打包 | ¥1280–1980 |
| 题库会员 | 只买题库（不含视频） | ¥199 / 考季 |
| 模考冲刺包 | 考前 2 个月，10 套押题卷 + 讲解 | ¥399 |
| 人工批改 | 实务案例题按篇批改 | ¥199 / 10 篇 |
| 增项专享 | 只买实务一科 | ¥399 |

### 转化漏斗埋点

```
落地页 PV → 试做每日一练 → 注册 → 完成 3 道题（AHA 时刻）
→ 弹出「你的正确率 42%，超过 XX% 考生」→ 付费墙（第 10 题触发）
→ 下单 → 支付 → 首课完播 → 7 日留存
```

关键指标：**注册→首答完 3 题转化率**（目标 > 55%）、**付费墙曝光→支付转化率**（目标 > 4%）、**次日留存**（目标 > 35%）。

## 6. 冷启动运营方案

### 6.1 题库建设路径（合规优先）

| 阶段 | 目标题量 | 来源 |
|---|---|---|
| 冷启动（第 1 个月） | 6000 | 教研团队按考纲原创仿真题 + 公开教材知识点改编 |
| 成长期（2–3 月） | 12000 | 授权题库采购 + 用户 UGC 投稿（审核后入库） |
| 成熟期（4–6 月） | 20000+ | 持续原创 + 授权增量 + 社区共建 |

> **注意**：真题原文涉及版权，**必须通过授权采购**。平台不自行抓取。详见 `docs/07-题库合规与导入规范.md`。

### 6.2 获客渠道

1. **内容 SEO**：考点解析页 + 一建问答页，Next.js SSR 保收录
2. **微信生态**：公众号「每日一练」卡片，分享带邀请码
3. **工地社群**：项目经理群、施工员群，用「免费估分/对答案」为钩子
4. **查分节点**：12 月查分期是全年最大流量窗口，提前布局估分工具
5. **老带新**：邀请得会员天数，双向奖励

### 6.3 关键运营动作日历

| 时间 | 动作 |
|---|---|
| 3–5 月 | 新考季启动，早鸟价，拉新 |
| 6 月 | 报名期，报名提醒 + 报名指导直播 |
| 7–8 月 | 冲刺期，模考大赛（排行榜激励） |
| 9 月 | 考前押题、考点速记、考前心理安抚 |
| 9 月考后 | 对答案、估分、复盘报告 |
| 12 月 | 查分 + 取证，转化二战学员与增项学员 |
