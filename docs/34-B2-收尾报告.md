## 3. 意外收获

### 3.1 ★★ 产品缺陷 1 个（P0，由走查器当场抓到）—— `cca6e8c`
**症状**：PWA 里**选完科目永远建不出练习**（章节列表恒空，页面显示「这门科目还没有章节」）；
同族：`toggleFlag` 用 URL 的**字符串** qid 查 `idbGet("questions", qid)`，而库里的 id 是**数字** ⇒ 标记 / 收藏一律 `40401`。

**根因**：`importBank` 把包里的 JSON id **原样写库**（数字），而 URL 段 / 查询串给的是**字符串** ⇒
`c.subject_id === sid` 这类**严格比较恒为假**。实测对照：`=== String(s0.id)` → **0 条**；`=== s0.id` → **3 条**。
★ 已排除精度（id 最大 9 位 ≪ 2^53）；★ `types.ts` 声明 `id: string` —— **类型是假的**（不变量 8 的反例）。

**修法**：**在边界上统一形状**（`asId()` 唯一转换点 + `normalizeIds()` 按名字认 id 字段），**不在比较点打补丁**。
**判据两处，各管一半**：**静态** = 不变量 14（`seg[n]` / `query.get("<…id>")` 必须在 `asId(` 里）；
**行为** = 走查器 `setup` 的 **③b**（读库断言 id 全是字符串）。
★★ **静态只能证明"代码走了 `asId`"，行为才能证明"写进库的真的归一了"** —— 这句是本批最值钱的一句。

### 3.2 ★★ 判据自身的缺陷：**UI 会把"库里的事实"盖住**（`notes` 场景挖出来的）
把 `editNote` 变异成"插一条新的" ⇒ **面板只显示 1 条**（旧那条被内存态盖住），**只断言 UI 条数根本看不出来**；
而**库里已经是 2 行**。⇒ 判据改成 **库里行数 == 1**，放在该步的**最前面**（UI 是产物、库里的行才是事实）。
★ 这条已提升成通用判据（`MEMORY.md` 验证套路：「UI 是投影，数据的状态要在数据层断言」）。

### 3.3 ★★ 一条**被自己推翻的**判断："拿不到" ≠ "没实现"
我先前判："章节练习答对**不该**给 `retry_correct`"这条**覆盖不了** —— 理由是"题一答错就落到
'没做过的在后'的排序尾部 ⇒ 新的章节会话里不会有它"。
**实测推翻**：`createSession` 确实**拒绝**"章节会话 + 指定题集"（`question_ids` 只在 `mode='wrong'` 下有意义，
与后端同口径 —— **设计上不支持**）；**但不需要它**：挑一个"**可判分题数 ≤ 10**"的章节（页面写死 `SESSION_SIZE = 10`），
**整章都会进会话** ⇒ 指定题一定在里面。⇒ 补成 `wrong` ⑧，**变异**（去掉 `s.mode === "wrong"` 闸）后精确变红，
库里 `retry_correct: 2` —— 正是代码注释里"曾经做错"的那个 bug。
★ **提炼**：「做不到」是关于**问题本身**的判断，「没实现」是关于**当前代码**的判断 —— 混在一起会把
"换个思路能做的事"当成"永远做不到的事"。⇒ **说"拿不到"之前，先问"换个构造方式行不行"**。

## 4. 没验的 / 口径要说清的（**不假装查过**）

### 4.1 ⏭ 判据 6「跨会话一致」**没有断言**
`grep` 走查器：无任何"第二/另一个会话"的断言。现有最接近的是 `marks` ③「刷新后仍在」——
那验的是**持久化**，不是**跨会话**（同一道题在两个不同 session 里都显示已标记）。
★ **可构造性**：`wrong` ⑧ 已经用到了那个技巧 —— 挑"可判分题数 ≤ 10"的章节，**整章都会进会话** ⇒
进出同一章两次即可保证两次会话含同一题。⇒ 这条**能补**，属"漏做"而不是"做不到"；列进 §6。

### 4.2 `loop` ⑦ 的构造**不是"换题库"**（必须说清）
用户原话是"**换包后**四类记录同时还在"。**实测做不到**：PWA 里让一道题消失的**唯一**途径是「换题库」，
而 `importBank` 调的是 `db.ts::wipeAll()` ⇒ **连用户数据一起清空**（页面也明写"这会清空你的全部数据"）。
⇒ **`question_available=false` 这一态没有写入路径**（硬约定 F：状态"可达" ⟺ 有任何接口能写入它）
⇒ "换包后记录仍在"**不可达**。
于是 ⑦ 用**可达**的构造：导出备份 → 把四类记录的题号改成"库里没有的题" → **走真 UI 恢复**，
这正是**题目下架**在本地的等价物。**报告与代码注释里都明说它不是换题库**。
★ 边界已写进 `docs/32` §4.1.1；想改成"换题库也保留" ⇒ **`docs/21` BL-30**。

### 4.3 ⏭ 新加的不变量 13 / 14 **不在 `mutate-invariants.py` 里**
