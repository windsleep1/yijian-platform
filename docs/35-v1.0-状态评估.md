## 6. 「v1.0」的口径（**什么算完成**）

同时满足四条 ⇒ 记为 **v1.0**：

1. **三端各有"一句话的功能面 + 一条可核判据"**（§1），且都 ✅；
2. **线上三段同 SHA，且 == `HEAD`**（§2），并有人工实测"能打开、能操作"；
3. **最新 CI 在 step 级全绿**（§3）—— 不是"本地全绿"，也不是只看一个 `conclusion`；
4. **作品集 A/B/C/D 四项**要么"有物证"，要么**被点名成缺口**（§4 / §5）。

★★ **v1.0 ≠ 没有缺口** —— 而是"**缺口被点名、且都不阻塞对外演示**"。
★ 之后任何一次"往仓库加东西"，都应按 `docs/26` §5 的六条判据 + 本文 §2/§3 **重新量一遍**再宣布新版本。
